# Coding Practice & Progress Tracker

Coding Practice & Progress Tracker is a web application designed for B.Tech CSE students to practice coding problems and track their programming progress.

## Features
- Student Dashboard
- Coding Practice
- Daily Coding Challenges
- Progress Tracking
- Goals
- Achievements and Badges
- Leaderboard
- Coding Notes
- Profile Management

## Technologies
- HTML
- CSS
- JavaScript
- Base44 AI
- Database
